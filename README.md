# 記帳アプリの説明資料

GitHubアカウントなしでダウンロードできます。

[説明資料をダウンロード（ZIP）](https://github.com/suehiro111440-code/kicho-user-guide/releases/latest/download/kicho-guide.zip)

## 開き方

1. パソコンで上のリンクからZIPをダウンロードします。
2. ZIPを右クリックし「すべて展開」を選びます。
3. 展開したフォルダの `index.html` をダブルクリックします。

全9ページです。8ページ目の「二重チェックの詳しい方法を見る」から別の説明ページに進めます。
フォルダ内のファイルは一緒に保管してください。5ページ目では操作の詳細をクリックで開けます。

実際の業務データ・APIキー・アプリ本体のソースコードは含まれていません。
画面のお客様名や書類は架空例です。確認担当者の表記はご利用環境に合わせて読み替えてください。
