# 記帳アプリの画面付き説明資料

統合試用版2026.11.15.3の操作をまとめた10ページ資料です。通帳の日付自動変換と、確認が必要な日付だけを選ぶ操作を実画面で説明しています。

[説明資料PDFをダウンロード](https://github.com/suehiro111440-code/kicho-user-guide/releases/download/v2026.11.15/kicho-guide.pdf)

[説明資料をまとめて保存](https://github.com/suehiro111440-code/kicho-user-guide/releases/download/v2026.11.15/kicho-guide.zip)

[アプリ2026.11.15.3をダウンロード](https://github.com/suehiro111440-code/kicho-app/releases/download/v2026.11.15.3/KichoApp_Setup_2026.11.15.3.exe)

新版のアプリはダウンロードとインストールが必要です。対応する前回の作業は「前回の続きから開く」でコピーして続けられます。

通帳の取引日欄・対象年や期間などから特定できる日付を、西暦へ自動変換します。「② 一覧を確認」では変換件数と根拠を確認できます。不明な日付は「日付が不明な行を選択」から、原本と元号・年を確かめて入力します。

今回の操作は「その他」→「新しい作業」から、架空資料を少量で試せます。Google保存済みの作業は、②で同じ一覧の確認・修正を続けます。

[前回の架空通帳](https://github.com/suehiro111440-code/kicho-user-guide/releases/download/v2026.10.25/sample-bank.pdf)で、①読取・②確認・③台帳とCSVの一般操作を試せます。

資料は架空画面を使用しています。配布先PCの新版操作と弥生への取り込みを、次の試用で確認します。
